## ✨ Funcionalidades
- 💬 Chat com streaming de respostas (tempo real)
- 🧠 Histórico de conversa por sessão
- 🔄 Reset de conversa
- 🌐 Interface web premium incluída
- 🤖 System prompt especializado em código e IA

## 🛠️ Setup
```bash
npm install
cp .env.example .env  # Adicione GEMINI_API_KEY
npm run dev
# Aceda: http://localhost:3000
```
